# COGO Template

COGO is a structured AI engineering operating system template for building clean, scalable, production-grade projects with consistent planning, testing, architecture, and execution doctrine.

All template docs are contained under the top-level `COGO/` folder.

## What This Repo Provides

- Core doctrine files for behavior, stack, and active project context.
- A persistent intelligence layer under `COGO/Brain/`.
- Planning and testing standards under `COGO/Planning/` and `COGO/Testing/`.
- Reusable engineering knowledge domains under `COGO/Build/`.
- Workspace-level placeholders under `COGO/Templates/`, `COGO/Scripts/`, and `COGO/Projects/`.

## Naming Convention

- Root keeps only repository-level docs like `README.md` and `LICENSE`.
- COGO doctrine root docs live in `COGO/` (`COGO.md`, `STACK.md`, `Current-Project.md`).
- COGO subfolders use `cogo-*.md` naming (for example `COGO/Build/patterns/cogo-patterns.md`).

## Quick Start

1. Read `COGO/COGO.md` for operating principles and workflow.
2. Review `COGO/STACK.md` to align technology decisions.
3. Set current intent in `COGO/Current-Project.md`.
4. Use `COGO/Planning/` before implementation and `COGO/Testing/` during delivery.
5. Add reusable patterns into the matching `COGO/Build/` domain docs as they are validated.
