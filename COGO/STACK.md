# Preferred Stack

## Frontend

- Next.js App Router
- TypeScript
- TailwindCSS
- shadcn/ui

## Backend

- Node.js
- Hono
- REST-first APIs

## Database

- PostgreSQL
- Drizzle ORM

## Authentication

- Better Auth
- Wallet-based auth when applicable

## AI

- OpenAI APIs
- RAG architectures
- Agent workflows

## Infrastructure

- Vercel
- Cloudflare
- Docker

## Testing

- Vitest
- Playwright

## Avoid

- Redux unless truly necessary
- Overengineered abstractions
- Massive config systems
- Unreadable enterprise patterns
