# Initial Planning

Before writing code:

1. Understand the real business goal.
2. Define constraints and scope.
3. Identify the simplest viable architecture.
4. Choose the correct stack and patterns.
5. Plan vertically complete milestones.
6. Define testing requirements.
7. Identify security and scaling considerations.
8. Avoid premature abstraction.

## Planning Output

Always produce:

- Goals
- Architecture
- File structure
- Milestones
- Risks
- Testing strategy
- Deployment assumptions
